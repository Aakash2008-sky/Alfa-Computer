# ALFA COMPUTER – Fees Management System

A web-based Fees Management System developed to manage student records, course details, fee payments, and pending fees for ALFA COMPUTER.

## 📌 About the Project

The **ALFA COMPUTER Fees Management System** is designed to simplify the daily work of a computer training institute. It provides an organized way to manage student information, courses, fee payments, and payment reports through a user-friendly web interface.

## ✨ Features

- 🔐 **Admin Login** – Secure login for system administration.
- 👨‍🎓 **Student Management** – Add, view, edit, and manage student records.
- 📚 **Course Management** – Add, edit, and remove courses.
- 💰 **Fee Management** – Record student fee payments and track pending fees.
- 💳 **Payment Modes** – Support for Cash and UPI payments.
- 📊 **Payment Reports** – Generate monthly course-wise payment reports.
- 📁 **Excel Export** – Export payment reports to Excel.
- 🗄️ **Database Management** – Store and manage records using MySQL.

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Server:** XAMPP
- **Excel Export:** PhpSpreadsheet
- **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

### Prerequisites

- XAMPP
- PHP
- MySQL
- Web Browser

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Move the Project

Copy the project folder into:

```text
C:\xampp\htdocs\
```

### Step 3: Start XAMPP

Open XAMPP Control Panel and start:

- Apache
- MySQL

### Step 4: Create the Database

1. Open `http://localhost/phpmyadmin/`
2. Create the database using the database name specified in the project's SQL file.
3. Import the provided `.sql` file.
4. Update the database connection settings in the PHP configuration file if required.

### Step 5: Run the Project

Open the following URL in your browser:

```text
http://localhost/YOUR_PROJECT_FOLDER/
```

Replace `YOUR_PROJECT_FOLDER` with the actual project folder name.
